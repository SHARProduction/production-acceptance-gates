# SHAR Production Acceptance Gates

This dataset by **[SHAR Production](https://sharprod.com/)** contains 47 authored bilingual acceptance gates. A gate requires verification evidence, corrected state, accountable ownership and a documented downstream decision.

`gates.jsonl` contains one gate per line. `gates.json` contains the complete collection. The authored taxonomy and text use **CC-BY-4.0**. The [interactive source](https://github.com/SHARProduction/production-acceptance-gates) and documentation use MIT.

No client data, credentials, analytics or performance claims are included. AI assistance was used to draft and validate the material under SHAR Production's publishing responsibility.
